# 小规模数据降维策略与算力边界规范

受限于单机硬件条件（无重型 GPU / 内存通常 16–32 GB），文献复刻的目标是**高保真复现分析方法链路与发表级出图模板**，而不是重跑原论文动辄百万细胞或全 TCGA 队列的计算负载。

## 数据选用优先级

1. **P1 — 原文公开小体量数据或公开库真实抽样子集（首选）**：
   - 从原文 `Data Availability` 检出的 `GEO` / `Zenodo` / 作者 GitHub `example/` 获取最小真实样本。
   - **单细胞（scRNA-seq / snRNA-seq）**：按细胞类型（CellType）与疾病/处理分组**分层抽样至 `1,500–2,500` 个细胞**（确保每组、每个主要亚群至少保留 `>= 40–80` 个细胞，避免后续 `CellChat` / `hdWGCNA` / `FindMarkers` 退化）。
   - **Bulk RNA / 蛋白组 / 临床生存队列**：取单一代表队列或随机分层抽样 **`60–120` 例样本**（保持事件/结局正负样本比例一致）。
   - **空间转录组**：保留单张典型切片或裁剪核心 ROI（`<= 2,000` spots）。
2. **P2 — 公开同类小样本或合成结构验证集（需先征询作者）**：
   - 当原论文数据需申请受控权限（如 dbGaP / GSA-Human）、文件过大（>1 GB）或未公开时，停下列出缺口并由作者确认使用：
     - 同组织/同设计公开小数据集；或
     - 严格匹配接口列名、值域与图面视觉特征的固定种子合成数据（明确标注 `synthetic visual approximation`）。

## 运行资源与诚实声明硬规则

- 单步分析脚本目标控制在本机 **10–15 分钟内** 可完成；所有抽样脚本必须固定随机种子（默认 `seed = 42`）并记录保留的原始 ID 与抽样脚本路径。
- 在以下 3 处位置必须同步写明降维边界，**严禁将小样本结果写成原论文统计结论复现**：
  1. `<paper_dir>/plan.md` 与 `extracted/` 总结；
  2. 产出图模板的 `qa_report.md` 与 `README.md`；
  3. 入库后 `workflow` 页的 `## 不适用` 与 `scale_down_boundary` 字段。
