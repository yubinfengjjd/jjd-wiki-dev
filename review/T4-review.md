## 审查中修改

1. **退回没有状态检查**：原来已经是 ready 或 archived 的模板也能被退回，画廊会被改回 draft。改为只允许 pending_signoff 和 pending_template（后者相当于撤回签核），其他状态返回 409。测试：归档后退回返回 409。前端同步：待模板化状态显示“撤回签核”按钮。
2. **WikiError 显示成 “Internal Server Error”**：没有处理器，git 失败之类的错误在页面上看不到原因。加了和 cli.main 同样的边界处理，返回 500 和错误信息。测试：删掉 .git 后收藏，detail 中包含 git 报错。
3. **日志同一分钟内顺序颠倒**：按时间字符串排序，同一分钟的记录保持文件里的先后顺序，结果最旧的排在最前。log.md 只追加，直接倒序即可。原测试断言的是“按时间排序”，已改为断言追加顺序。
