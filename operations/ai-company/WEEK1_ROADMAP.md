# AI Company · 第一周交付与验收清单

- [ ] **CEO**：确认两个 GitHub 仓库及该提案，不在审核前合并到 main。
- [ ] **COS**：在 Grok Bot 创建第一个 CEO Office COO Bot，设置长期规则与权限边界。
- [ ] **Scout**：只读访问 GitHub 和公开文献 API；手动核对 Europe PMC 数据和 DOI。
- [ ] **Curator**：核对现有 Wiki 的 `catalog.jsonl`，对候选按研究目的/适用场景/许可证评分并去重。
- [ ] **Pilot**：下载第一版独立工程包，执行离线测试；手动触发 Scout 工作流，确认 API 的真实请求可用。
- [ ] **CEO**：选定首个可合法复用的图形/方法来源，并批准具体依赖和任务预算。
- [ ] **Builder**：在独立 worktree 中复现一项，留原样运行、新数据、异目录验证证据。
- [ ] **QA**：独立环境审核源、统计与许可；fail/not_run 精确记录。
- [ ] **Librarian**：遵循 L0/L1/L2 和公司原有知识结构生成待确认 Wiki 条目，不自动 ready。
- [ ] **CEO**：审批第一批产物后，再启用正式日程和 PR/前端发布。

**失败定义**：仅收论文截图、未经授权转载原图、编造复现结果、没有代码/理论双层产物、只提交 GitHub 未核验前端，都不算正式入库。
